# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**, as its code of
conduct. The full text is available at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

In short: be respectful and constructive, welcome people of all backgrounds and
experience levels, accept feedback gracefully, and focus on what is best for
the project and its community. Harassment, insults, personal or political
attacks, and publishing others' private information are not acceptable.

## Scope

This code applies in all project spaces — issues, pull requests, discussions
and reviews — and when an individual officially represents the project.

## Reporting

Report unacceptable behaviour privately to the project maintainer,
[@shushruth21](https://github.com/shushruth21), through GitHub. Reports will be
reviewed and handled confidentially as far as possible. The maintainer may
remove, edit or reject contributions and may temporarily or permanently ban
contributors whose behaviour violates this code.
